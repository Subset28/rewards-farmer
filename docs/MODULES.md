# Modules

Generated by `python scripts/modules_doc.py`; do not edit by hand.

## Runs the accounts

- `src/main.py`: One full daily run: for each account, every Rewards task (daily set, Explore on Bing, cards, quests, bonus points, searches), then the points reading and its alert
- `src/daily_loop.py`: Runs main.py once a day at an anchor hour plus a random delay, forever. Each loop it also checks health (health.py) and takes the day's backup (backup.py)
- `src/search_scheduler.py`: Spreads each owner's required searches over the day in several runs of search_only.py, keeps a journal so a restart catches up, and stops runs when the quota is complete
- `src/search_only.py`: One search run: the required searches up to today's target for the accounts it serves, and nothing else
- `src/rewards_tasks.py`: Every Microsoft Rewards task the bot does on the page: daily set, Explore on Bing, required searches, cards, quests and bonus points
- `src/browser.py`: Starting Edge for an account, and saying why it did not start
- `src/tab_utils.py`: Finding, switching to and closing browser tabs, including the blank ones Edge opens by itself
- `src/quests.py`: Which quest (punch card) tasks the bot will do, and which it leaves alone
- `src/element_selectors.py`: Where things are on the Rewards and Bing pages, in one place, so a change to a page is a fix in one file
- `src/desktop_utils.py`: Windows Virtual Desktop utilities
- `src/signin.py`: Sign a profile in from inside the container

## What it searches for

- `src/queries.py`: Where search queries come from
- `src/query_sources.py`: Search queries from public feeds instead of a language model
- `src/query_history.py`: What each account has already searched for
- `src/openrouter_queries.py`: Search queries from OpenRouter's free models, within a hard daily budget
- `src/llm_utils.py`: Search queries from a language model (a local Ollama server or an OpenAI-compatible service), and random nouns for the fallback
- `src/search_behavior.py`: Pacing and imperfection for the required searches
- `src/trawl_client.py`: Fetch a public page through trawl when a plain request is refused
- `src/chains.py`: Searching in tangents, the way a person does
- `src/reading.py`: How a person reads a page: a plan of scrolls, pauses and small movements of the hand

## Behaves like a person

- `src/behavior.py`: Per-account typing and mouse behavior
- `src/mimic_typing.py`: Types text the way a person does: the account's own rhythm, and, when switched on, slips that are noticed and fixed
- `src/mouse_trajectory.py`: Moves the pointer along a curved path at a human speed (Fitts' law) to an element and clicks it
- `src/pointer_path.py`: A pointer path shaped like a particular person's
- `src/human_model.py`: How much a person varies, at three levels, as numbers the bot can draw from
- `src/pace.py`: The bot's pauses between actions, spread the way a person's are
- `src/pacing.py`: Keeps an account from looking like a machine that does the maximum every day
- `src/schedule_plan.py`: Today's plan, kept across restarts
- `src/features.py`: Switches for behaviour changes that go live one at a time, per account
- `src/footprint.py`: Keeps the idle bot nearly free and each run polite to the rest of the NAS
- `src/memory_guard.py`: How close the container is to its memory limit, so a long run can back off before it is killed

## Keeps itself safe and visible

- `src/safety.py`: The brake: stop the bot when the account shows signs of trouble
- `src/notify.py`: Push notifications for things that need a human
- `src/health.py`: Tells a person, in Discord, when the bot needs them, and says what to do about it
- `src/task_log.py`: A record of how each task went in each daily run, so a task that has quietly broken can be seen
- `src/journal.py`: A record of what ran and how far it got, that survives a restart or a new build
- `src/run_lock.py`: One run at a time on the profile
- `src/points_log.py`: A running record of points, and how far off the next level is
- `src/status.py`: Everything worth knowing about right now, in one place
- `src/backup.py`: A daily copy of the small files that would be painful to lose
- `src/clock.py`: One clock for every date the bot decides things by
- `src/accounts.py`: Which accounts a run works through
- `src/constants.py`: Paths the rest of the code is built from: the repo root, data-dir and the .env, resolved from this file so the working directory never matters
- `src/log_utils.py`: Central logging configuration

## One VPN per account

- `src/vpn_config.py`: One OpenVPN tunnel and one iptables kill switch per account, in one container
- `src/isolation.py`: Run an account's browser inside that account's own VPN namespace

## Recording a person's hands, and checking the result

- `src/calibrate.py`: Record a person's own typing and mouse habits into a behavior profile, in one sitting
- `src/calibration.py`: What is measured in a calibration, and how it becomes a behavior profile
- `src/mouse_fit.py`: Reading a person's pointer movements back into the numbers pointer_path.py draws from
- `src/indistinguishable.py`: Can a classifier tell a person's real typing from the bot's, given only the person's own numbers?
- `src/make_behavior_profile.py`: Build an account's behavior profile from a person's own recordings
- `src/typing_test.py`: A typing test that records the rhythm of your keystrokes
- `src/fitts_law.py`: Measure Fitts-law constants a and b from repeated target-click trials
- `src/recordpress.py`: The original tool that recorded keypress timings; calibrate.py replaces it
- `src/analyze_keypresses.py`: The original analysis of keypress_times.txt into 0.1 s buckets; calibration.py replaces it

## Diagnostics and one-off tools

- `src/check_selectors.py`: Report which selectors resolve against the Rewards UI you actually get
- `src/fingerprint_probe.py`: Compare browser identity variants on a throwaway profile, never an account's
- `src/typing_events_probe.py`: What a web page sees when the bot types as a recorded person: every key event, with its timing
- `src/mouse_events_probe.py`: What a web page sees when the bot moves the pointer: every mousemove, with its timing and position
- `src/serp_probe.py`: What a Bing results page offers a person to follow next, found from a real page
- `src/chain_probe.py`: Run the tangent runner in a real browser and watch memory, to see whether a long run fits the container's limit
- `src/inspect_rewards.py`: Read-only: save what each account's Rewards pages say, to find out what a page offers
- `src/vpn_browser_check.py`: Does Microsoft challenge a browser on this address? Checked on a throwaway profile, never an account's
- `src/visualize_trajectory.py`: A pygame window that draws the pointer path model, for looking at how it moves
- `src/visualize_bezier_distortions.py`: Display a Bezier path with an optional, temporary distortion overlay
- `src/random_image_for_visual_search.py`: Makes the random image the Visual search task uploads

## Other (place these in a group)

- `src/control_api.py`: A small control interface for the running app: look at it and stop or restart it without scripts
- `src/gate.py`: The gate: an account runs only with a recorded profile of how its owner types and moves
- `src/supervisor.py`: Runs several commands in one container and stops when any of them ends, so Docker restarts the container
